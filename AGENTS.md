# Repository instructions

Read and follow [`CLAUDE.md`](./CLAUDE.md) in full before changing this
repository. It is the shared source of truth for working practices, branch and
commit conventions, verification requirements, content rules, and known
technical traps.

When changing scrolling or animation behavior, also read
[`docs/ANIMATIONS.md`](./docs/ANIMATIONS.md). For architecture and ownership
boundaries, read [`docs/ARCHITECTURE.md`](./docs/ARCHITECTURE.md). Check
[`STATUS.md`](./STATUS.md) before starting broader work.

Do not duplicate the contents of `CLAUDE.md` here. Keeping one shared document
prevents instructions for Claude and Codex from drifting apart.
